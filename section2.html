Subdomain 2.2: Remove outliers based on standard deviation or IQR

Question 8
Which mathematical expression correctly calculates the Interquartile Range (IQR) for a numeric feature?
  • A) IQR = 75th percentile + 25th percentile, serving to effectively measure the data's central tendency.
  • B) IQR = 75th percentile - 25th percentile, serving to effectively measure the data's statistical spread.
  • C) IQR = 90th percentile - 10th percentile, serving to effectively measure the data's statistical spread.
  • D) IQR = 90th percentile + 10th percentile, serving to effectively measure the data's central tendency.
View Answer & Explanation
Correct Answer: B
Explanation: The Interquartile Range (IQR) measures the spread of the middle 50% of the dataset. It is strictly calculated by subtracting the first quartile (25th percentile) from the third quartile (75th percentile).
Question 9
When removing outliers using the standard IQR methodology, how are the valid lower and upper boundaries defined?
  • A) Lower = Q1 - 1.5 * IQR and Upper = Q3 + 1.5 * IQR establish the valid baseline threshold.
  • B) Lower = Q1 - 2.0 * IQR and Upper = Q3 + 2.0 * IQR establish the valid baseline threshold.
  • C) Lower = Q1 - 1.0 * IQR and Upper = Q3 + 1.0 * IQR establish the valid baseline threshold.
  • D) Lower = Q1 - 3.0 * IQR and Upper = Q3 + 3.0 * IQR establish the valid baseline threshold.
View Answer & Explanation
Correct Answer: A
Explanation: The standard Tukey method for outlier detection defines the inner fences (boundaries) as 1.5 times the IQR below Q1 and above Q3. Values outside this range are considered outliers.

Question 11
When using the standard deviation method to remove outliers, which condition typically defines an outlier in a normal distribution?
  • A) A data value that strictly falls outside Mean ± 1 * Standard Deviation is classified as a severe outlier.
  • B) A data value that strictly falls outside Mean ± 2 * Standard Deviation is classified as a severe outlier.
  • C) A data value that strictly falls outside Mean ± 3 * Standard Deviation is classified as a severe outlier.
  • D) A data value that strictly falls outside Mean ± 4 * Standard Deviation is classified as a severe outlier.
View Answer & Explanation
Correct Answer: C
Explanation: Under the empirical rule for normal distributions, 99.7% of data points fall within 3 standard deviations of the mean. Consequently, values beyond ±3 Standard Deviations are universally treated as outliers.
Question 12
Why might a Data Scientist preferentially select the IQR method over the Standard Deviation method for removing outliers?
  • A) The IQR method remains highly sensitive to massive extreme values, making it ideal for deeply skewed distributions.
  • B) The IQR method remains highly resistant to massive extreme values, making it ideal for deeply skewed distributions.
  • C) The IQR method remains mathematically identical to standard deviation, making it ideal for perfectly normal distributions.
  • D) The IQR method remains computationally faster than standard deviation, making it ideal for perfectly normal distributions.
View Answer & Explanation
Correct Answer: B
Explanation: The Standard Deviation method relies on the mean and standard deviation, both of which are heavily distorted by extreme outliers. The IQR uses quartiles based on rank ordering, making it highly robust to outliers and better for skewed data.
Question 13
You have calculated mean_val and stddev_val for a column price. Which PySpark code correctly filters out values outside 3 standard deviations?
  • A) df.filter((col("price") >= mean_val - 3 * stddev_val) & (col("price") <= mean_val + 3 * stddev_val)) retains valid rows.

Question 14
If a feature contains highly right-skewed data with massive extreme values, how is the standard deviation method impacted compared to IQR?

Subdomain 2.5: Compare and contrast imputing missing values with the mean/median/mode

Question 29
Under what exact data condition is mean imputation generally scientifically preferred over median imputation for a continuous feature?

Question 31
